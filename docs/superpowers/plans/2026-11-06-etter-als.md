# Etter-style parallel ALS implementation plan

> **For agentic workers:** Use superpowers:executing-plans inline with TDD and one independent numerical/concurrency review.

**Goal:** Implement the requested Etter-style tree ALS sweep with concurrent sibling local solves, existing tAMEn acceptance/invariants, and measured scaling.

**Spec/source:** User explicitly requests Etter parallel ALS. Etter (2016), Section4.2, Definition33 and Algorithm4, https://www.sam.math.ethz.ch/sam_reports/reports_final/reports2015/2015-25_rev2.pdf . Existing TTN space-time discretization, residual updates, warm starts and global acceptance stay in place.

**Architecture and numerical choice:** SVD child orthogonalization captures each child's operator/RHS complement while that complement is orthonormal. Rotate cached upward contractions with Vt before preparing the next sibling, then freeze both complements and visit siblings independently. Recompute child upward messages after QR on return. The parent is solved again in the updated child bases. For its starting vector, project its pre-branch coefficients into those updated bases using mixed overlaps with the original child bases. This avoids Etter's inverse-singular-value connector reconstruction; the final projected linear problem is the same, although finite-tolerance Krylov paths may differ. Retain null SVD directions without division/regularization.

## Constraints and interfaces

- Work in the existing uncommitted dev/als checkout; preserve unrelated work, no automatic commits.
- Public `als_sweep=:serial` (existing default) or `:etter`; `threaded=false` serializes the same Etter algorithm for scaling/reference. Forward through fixed/adaptive HEOM and retain warm starts.
- New `_tamen_etter_sweep!(x,A,b,time_leaf;tol,krylovdim,krylov_maxiter,workspace,threaded)` returns the same counters as the existing sweep plus task counts. Only successful joined sweeps commit tensor dictionaries.
- Worker-owned node-indexed tensor/scratch/stat slots; no concurrent Dict mutation. Commit updated node scratch to TAMEnWorkspace and counters on caller thread. Borrowed scratch is exclusive under the existing workspace lease.
- Parents wait for every started child even on exceptions; propagate original TAMEnConvergenceError. No partial tree publication.
- Full time leaf remains fixed. At the space/time root only the spatial child is active and receives the entire thread budget.
- Keep residual ALS, truncation and global verification sequential. Root invariant repair stays the existing serial root solve.
- `timings.sweep_seconds` isolates the solution sweep; `als_seconds` still includes protected truncation/root repair; these overlap. `als_parallel_tasks` records sibling tasks.

## Review focus

1. Complex SVD/transpose conventions, rectangular/shrinking ranks, zero/null singular values and strongly ill-conditioned local cores.
2. Cached environments must use the virtual rotated sibling bases, not actual singular-value-weighted child data.
3. Join all tasks on failure; no shared parent-core/Dict/counter writes or shared node scratch.
4. Fixed time leaf, arbitrary topology/root/physical leaf order and invariant restoration.
5. Threaded and serialized Etter arithmetic/order should agree; compare with sequential ALS by residual/state accuracy, not iteration identity.
